# 车次检票口、停台及出站口

## OpenAPI Specification

```yaml
openapi: 3.0.1
info:
  title: ''
  description: ''
  version: 1.0.0
paths:
  /api/v2/getExit:
    get:
      summary: 车次检票口、停台及出站口
      deprecated: false
      description: >-
        获得车次在指定车站停靠的站台、检票口和出站口。


        正常车站应当都能获得上述信息。如果获取不到，有可能是车次不停靠这个车站，也有可能是因为这个车站是无人车站/乘降所，不维护检票等信息。获取不到时所有值均为空。
      tags:
        - V2
      parameters:
        - name: trainNum
          in: query
          description: >-
            车次号。对于复车次，此车次号应当为在该站的车次号；如果在该站变更了车次号，则只有使用变更前的旧车次才能获得信息，此站以后的车站使用变更后的新车次。
          required: true
          example: G1
          schema:
            type: string
        - name: stationTelecode
          in: query
          description: 车站电报码。
          required: true
          example: VNP
          schema:
            type: string
        - name: date
          in: query
          description: 日期，不填则默认当天。
          required: false
          schema:
            type: string
        - name: kind
          in: query
          description: >-
            查询模式。填写 arrival 时，车站必须不是始发站；填写 departure 时，车站必须不是终到站。其他情况下，填写
            arrival 和 departure 不影响返回结果。
          required: false
          example: arrival
          schema:
            type: string
            default: departure
      responses:
        '200':
          description: ''
          content:
            application/json:
              schema:
                type: object
                properties:
                  data:
                    type: object
                    properties:
                      entrance:
                        type: array
                        items:
                          type: string
                          description: 每一条可能是多个检票口，如 "22AB" 等，取决于车站如何维护信息。
                        description: 检票口列表。查询终到站时为空。
                      exit:
                        type: array
                        items:
                          type: string
                          description: 每一条可能是多个出站口，取决于车站如何维护信息。
                        description: 出站口列表。查询起始站时为空。
                      platform:
                        type: string
                        description: 站台编号。
                    required:
                      - entrance
                      - exit
                      - platform
                    x-apifox-orders:
                      - entrance
                      - exit
                      - platform
                  msg:
                    type: string
                    description: 请求消息。
                  success:
                    type: boolean
                    description: 请求成功标志。
                required:
                  - data
                  - msg
                  - success
                x-apifox-orders:
                  - data
                  - msg
                  - success
              example:
                data:
                  entrance:
                    - 二层12检票口
                    - 二层13检票口
                    - 负一层2快速进站厅12、13检票口
                  exit: []
                  platform: '13'
                msg: Succeeded.
                success: true
          headers: {}
          x-apifox-name: 成功
      security: []
      x-apifox-folder: V2
      x-apifox-status: released
      x-run-in-apifox: https://app.apifox.com/web/project/7299068/apis/api-406961130-run
components:
  schemas: {}
  securitySchemes: {}
servers: []
security: []

```
