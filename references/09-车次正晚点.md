# 车次正晚点

## OpenAPI Specification

```yaml
openapi: 3.0.1
info:
  title: ''
  description: ''
  version: 1.0.0
paths:
  /api/v2/getTrainDelayAll:
    get:
      summary: 车次正晚点
      deprecated: false
      description: |+
        获取一个车次的全部正晚点信息。

        正晚点代码含义如下：



        |代码|含义|
        |-|-|
        |ON\_TIME|正点|
        |ON\_TIME\_PREDICTION|预计正点|
        |DELAY|晚点|
        |DELAY\_PREDICTION|预计晚点|
        |EARLY|早点|
        |EARLY\_PREDICTION|预计早点|
        |MAINTAINCE\_MISSING|未维护|



        其中“未维护”通常是由于该车站是无人值守车站/乘降所，或者车站所在车务段懒得维护正晚点信息导致的。

      tags:
        - V2
      parameters:
        - name: trainNum
          in: query
          description: 车次。对于复车次，任何一个复车次都能查询。
          required: true
          example: G1
          schema:
            type: string
      responses:
        '200':
          description: ''
          content:
            application/json:
              schema:
                type: object
                properties:
                  data:
                    type: array
                    items:
                      type: object
                      properties:
                        delayStatus:
                          type: string
                          description: 延误状态的文本描述。
                        delayStatusCode:
                          type: string
                          description: 延误状态的代码。
                        delayTime:
                          type: integer
                          description: 延误时长。此数值恒为正值，需要根据延误状态判断早点还是晚点。
                        stationName:
                          type: string
                          description: 车站名。
                        stationTelecode:
                          type: string
                          description: 车站电报代码。
                      required:
                        - delayStatus
                        - delayStatusCode
                        - delayTime
                        - stationName
                        - stationTelecode
                      x-apifox-orders:
                        - delayStatus
                        - delayStatusCode
                        - delayTime
                        - stationName
                        - stationTelecode
                      description: 按照车站顺序排列。
                  msg:
                    type: string
                    description: 请求消息。
                  success:
                    type: boolean
                    description: 请求成功标志。
                required:
                  - data
                  - msg
                  - success
                x-apifox-orders:
                  - data
                  - msg
                  - success
              example:
                data:

                    delayStatusCode: ON_TIME

                  - delayStatus: 正点
                    delayStatusCode: ON_TIME
                    delayTime: 0
                    stationName: 上海
                    stationTelecode: SHH
                msg: Succeeded.
                success: true

          x-apifox-name: 成功
```
